## Gate A pass criteria (cmp_gate.py, scenarios.py)

- gate4: answer text of arm B byte-equal to arm A on every turn (exit 0 only if 10/10).
- scenarios: each probe answer from the live server byte-equal to a cold reference on a fresh server.
