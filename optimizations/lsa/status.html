Architecture

What we are building

The target is a trained, Qwen-specific compact query encoder that selects cold full-attention blocks while preserving exact DeltaNet SSM and convolution state outside the LSA path.

Labels come from Qwen teacher/oracle extraction
1. Source Long Qwen token streams

HF/local documents become little-endian int32 token files.

2. Teacher Frozen Qwen capture

Capture layer-46 hidden, pre-RoPE keys, and post-RoPE Q/K.

3. Oracle Future attention labels

Compute cold block mass with full causal softmax denominator.

4. Encoder Compact retriever

Train a small query encoder and emit deployable F16 weights.

5. Runtime Active packed KV view

Use selected blocks first, then add CPU/GPU residency later.

Risks

Known constraints and guardrails

Do not skip training

Important

Adaptive keep ratio and recency policies are useful baselines, but they are not paper-faithful LSA. The compact retriever must learn from Qwen teacher/oracle labels before we can claim LSA behavior.

Keep SSM state exact

Boundary

LSA should only select full-attention K/V blocks. DeltaNet SSM and convolution state remain exact and separate from sparse retrieval.

FlowKV is not the active sparse store

Boundary

FlowKV and PR274 restore compressed-prefix state and offer useful strip-copy/snapshot patterns. LSA still needs its own archival full-attention source and fixed-capacity active view.

MRCR-style dense retrieval can fail

Eval gate

The learned selector must be tested on scattered, dense-memory workloads where many distant chunks are simultaneously relevant.

User experience

The intended interface is --lsa-auto

LSA should deliver value without asking users to understand arena sizing, retrieval cadence, CUDA graph constraints, or benchmark failure modes. Manual flags remain for experiments; the product path should tune conservatively by default.

Pre-run calibration

Planned
  • Match artifacts: validate model fingerprint, encoder schema, and calibration manifest.
  • Estimate budget: model size, context length, TQ3/F16 cache type, draft residency, local window, and headroom.
  • Choose start plan: safe mode, bounded K, policy, interval, and fallback before generation.

Runtime adaptation

Planned
  • Adapt only safe knobs: active slots inside a preallocated maximum, stratified slots, cadence, and fallback.
  • Watch live signals: score entropy, top-score margin, selected-set churn, memory pressure, and DFlash accept rate.
  • Fail closed: no matching trained encoder means no silent untrained retrieval.

Offline planner exists now

Done

The current worktree implements the fail-closed planner as auto_plan.py. It emits a versioned JSON recommendation for the future server flag, and it can apply telemetry observations to graph-safe knobs. It does not change live inference. 

python3 auto_plan.py \
  --encoder /tmp/lsa-encoder \
  --calibration /tmp/lsa-calibration.json \
  --max-ctx 131072 \
  --agentic \
  --output /tmp/lsa-auto-plan.json

Optional observation input can adapt k, interval, and policy using memory pressure, selector confidence, selected-set churn, DFlash acceptance, no-context detection, and explicit long-memory hints.
